# @perufindocs/web

Next.js 14 (App Router) web application — the user-facing surface.

## Surfaces

- `/` — landing / query interface
- `/query/[id]` — saved query with shareable URL
- `/sources` — browse corpora and individual documents
- `/leaderboard` — public eval leaderboard across models
- `/docs` — embedded user documentation (ES + EN)

## Status

Scaffold only. UI implementation Week 3 onward.
